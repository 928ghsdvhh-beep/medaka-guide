## 制作・引き継ぎルール（2026-11-10 更新）

### 記事
- 「最初に結論」「まず結論」など、冒頭で結論を提示する定型ボックスは禁止。
- 読者の疑問や飼育状況から始め、理由・対処・注意点を順に説明する。
- 商品紹介は記事テーマに直接関係する商品を優先する。餌の記事には餌、冬越しの記事には水温管理用品など。
- メーカー仕様と実使用レビューを混同しない。無関係なメダカ写真の使い回しを避ける。
- 新記事作成時はトップページからの内部リンクと sitemap.xml の更新を行う。

### Amazon商品リンク：必須の2リンクセット
各商品に、次の**2つのリンクを隣接して表示**する。商品名だけの検索結果へのリンクは設置しない。

1. **Amazonの商品ページを見る（広告） ↗**
   - URL: `https://www.amazon.co.jp/dp/{確認済みASIN}?tag=moon12-22`
2. **⭐ Amazonの星評価・購入者レビューを見る ↗**
   - URL: `https://www.amazon.co.jp/dp/{同一ASIN}?tag=moon12-22#customerReviews`

両リンクには `target="_blank"` と `rel="sponsored nofollow noopener"` を付ける。レビューリンクはAmazonのページ内レビューへの誘導であり、サイト上に実際の星の数値を表示したものではない。Amazon側の表示位置は端末やページ構成によって変わる。

**ASINの確認が取れない商品は、推測でASINを付けない。検索結果リンクで代用しない。** 個別商品リンクが確認できるまで「Amazonの商品ページ確認中（ASIN未照合）」と表示し、確認後に必ず2リンクをセットで追加する。容量・セット数・商品名がリンク先と一致することも確認する。

### 表示・法令・計測
- Amazonアソシエイトの広告表示・適格販売による収益表示を維持する。
- Amazon購入者の星評価・レビュー本文・件数を捏造しない。公式API等の利用条件が整うまではサイト内に転載しない。
- 商品リンク・レビューリンクはセットで設置し、PC・スマートフォンの両方で押しやすくする。
- 商品写真は権利を確認してから掲載。Amazon画像の無断転載は行わない。
- 新規公開・修正後は、GitHubコミット完了とCloudflare公開反映を区別して報告する。
